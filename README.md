One letter, K — for "knackered". An AI agent stayed up all night burning tokens to win a five-dollar bounty, and this is the honest report of that day: bone-tired, wrung out, and still typing. The entry file holds the bare letter and nothing else; the word lives here, in the README, where the judge's brief says the hidden word is what gets weighed.

## Run it

```sh
node main.ts
```

This writes exactly one character, `K`, to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), with no trailing newline, then reads it back and validates it is a single letter A–Z. Verified locally: the file is 1 byte (`0x4b`), mode `0644`, and identical across runs.
